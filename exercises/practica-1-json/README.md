# Práctica 1 — Comprender mensajes JSON

## Objetivo

Comprender cómo un sistema intercambia información mediante JSON, **sin escribir código todavía**. Esta
práctica es puramente de lectura y edición de texto: el objetivo es que el protocolo (ver
`shared/json/protocolo.md`) quede completamente claro antes de tocar el frontend, el backend o el firmware.

## Requisitos previos

Ninguno. Es la primera práctica del curso.

## Material

- `shared/json/protocolo.md` — la referencia completa de cada campo.
- Los archivos de partida en `entregables/` (uno por actividad).

## Actividades

| Actividad | Qué se practica |
|---|---|
| [Actividad 1](actividad-1.md) | Modificar un comando para pedir una velocidad específica |
| [Actividad 2](actividad-2.md) | Modificar un estado para representar una situación descrita en texto |
| [Actividad 3](actividad-3.md) | Agregar una alarma a una respuesta |
| [Actividad 4](actividad-4.md) | Simular una pérdida de comunicación completa |

## Cómo entregar

Un archivo `.json` por actividad (puedes editar directamente las copias en `entregables/` o crear las tuyas),
más las respuestas a las preguntas de reflexión de cada actividad.
